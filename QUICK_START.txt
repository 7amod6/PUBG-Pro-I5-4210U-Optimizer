🐍 OPTION 2: PYTHON SCRIPT

Step 1: Install Python (if not already installed)
        Download from: https://www.python.org/downloads/

Step 2: Open Command Prompt as Administrator

Step 3: Navigate to this folder:
        cd C:\path\to\PUBG-Pro-I5-4210U-Optimizer

Step 4: Install dependencies:
        pip install colorama

Step 5: Run the optimizer:
        python optimize_i5_820m.py

Step 6: Follow the prompts

🔧 TROUBLESHOOTING

Problem: Script says "must run as Administrator"
Solution: Right-click the .bat file → "Run as administrator"

Problem: Python says "pip is not recognized"
Solution: Add Python to PATH or reinstall Python with PATH option

Problem: Still getting low FPS after optimization
Solution: 
  1. Lower resolution to 960x540
  2. Set Graphics to "Low"
  3. Disable more effects (Reflections, Bloom, etc)
  4. Close background applications

Problem: Want to revert changes
Solution: Run "Restore_System.bat" as administrator
